# NexoPlan — Site de Produtos Hotmart

Site institucional e comercial da NexoPlan para centralizar os três produtos digitais da marca:

- NexoPlan Precifica
- NexoPlan Gestão Financeira
- NexoPlan Negócio 360

## Objetivo

Apresentar a NexoPlan como um ecossistema de soluções para pequenos negócios — não apenas como planilhas isoladas — e direcionar cada visitante para o produto mais adequado.

## Estrutura

- `index.html` — landing page principal
- `styles.css` — identidade visual e responsividade
- `script.js` — navegação, animações e interações
- `assets/` — logo transparente e ícone da aba do navegador

## Links de compra

Cada solução possui um link direto para seu checkout na Hotmart:

- Precifica — `B107154291R`
- Gestão Financeira — `U107329608Y`
- Negócio 360 — `X107329706V`

O site também inclui prévias visuais das áreas principais de cada ferramenta, descrições orientadas a resultados, comparação por problema e modal acessível com os itens incluídos.

## Publicação

O projeto é 100% estático e pode ser publicado no GitHub Pages, Cloudflare Pages ou qualquer hospedagem estática.
